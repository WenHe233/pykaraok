# 字体、缺字、繁体

## 字体从哪里来

- 用户通常把字体放在歌词文件旁边，或者给一个字体包 zip。pykaraok 默认用 .ass 所在目录的字体和其中文件名含 font 或“字体”的 zip，其它情况用 `--fonts` 指定。
- 测字宽时，字体只在 pykaraok 进程内加载（Windows 的 FR_PRIVATE），不安装到系统。出图时把这些字体作为 libass 的 fontsdir。
- 用户在 Aegisub 里重新套用时，Aegisub 按系统已安装的字体测字宽，所以交付说明要提醒用户先装字体。

## 缺字

`pykaraok fonts check X.ass` 列出每个字体缺的字。缺字时，渲染器会换用别的字体画这个字，字形和宽度都会变。处理顺序如下：

1. 问用户能否换字体或换写法。用户说过“尽量不要换字”“字体不换”。
2. 用同一字体里结构相近的字拼：`pykaraok draw compose`。用 `--part 字@x0,y0,x1,y1+dx,dy*sx,sy` 取部件，坐标是字格的比例。
3. 从风格接近的另一款字体取字：`pykaraok draw text 字 --font 另一字体 --size 字号`。
4. 在模板里把这个字替换成绘图。宽度用拼出来的字的 advance，后面的字依次修正位置（12_IN 的补字 code once 就是这样做的）。
5. 用 `render zoom` 放大，和相邻的字对比粗细与基线。

## 繁体

```bash
pykaraok cht 歌词.ass -o 歌词_繁体.ass --styles 中文样式 --rule 你=妳
```

- 先确认用户要不要繁体版。之前有译者明确不希望作品被机器转繁体，转完要请用户校对。
- 繁体版一律另存为新文件，然后重新 build 和出预览，文件名加 `_繁体` 或 `_CHT`。
- OpenCC s2twp 按词组转换，使用台湾用字（著、裡、什麼）。没有 OpenCC 时退回 Windows 逐字转换，并给出提示。
- 字数变化的行会报出来，逐字 `\k` 的行要手工核对。
- 繁体字往往不在原字体里，转完会自动做字形检查，缺字按上一节处理。
