# 示例

每个子目录是一份模板源文件（`*.fx.lua`）和说明。前四个从以前交付的项目里用 `pykaraok extract` 抽出，只含模板和代码，不含歌词、视频和字体。新项目从最接近的一个复制过来改。

| 目录 | 来源项目 | 效果 | 模板写法 |
|---|---|---|---|
| `starter` | 新写 | 日文逐音节浮入、唱到时放大变色并洒闪光；中文整句淡入，垫柔光 | 用 fxlib（core、color、shapes、emit），最适合作为起点 |
| `ice_melt` | rrk-ass《リキッド・アイス》 | 未唱的字是冰晶，唱到时融化变暖色，长音凝出水滴，退场向下流走，尾句化作星光上升 | 多条 `template syl` 分层，参数集中在 COL、T、STY 三张表 |
| `watercolor` | kimishinu_07 ED | 每句背后渗开一笔水彩，带颗粒和干湿变化，字迹按墨色显现，静止时与原行逐像素一致 | 一条 `template line` 输出整句的事件列表；噪声加等值线生成水彩形状 |
| `strawberry_jam` | kimishinu_12_IN 插入曲 | 草莓逐字落下，屏幕角落的果酱罐随歌词涨高，最后一句盖上格子布；缺字用本字体轮廓拼出 | `template char`，整句只有开头一个 `{\k1}`；一条“罐子行”读取前面所有歌词的时间 |
| `live_chorus` | alma Live《A·I》 | 三位演唱者各一种描边色，合唱行彩虹渐变并随节拍流动；关键词有专属特效；曲目信息卡 | 预处理在 `code line` 里做，按 165 BPM 节拍网格对齐 |

## 构建

```bash
pykaraok build examples/starter/starter.fx.lua --lyrics 歌词.ass -o 歌词_特效.ass
```

模板里写死的样式名（`--@meta style=`、`style=`）要和歌词文件里的样式名一致，不一致时改模板或加 `--styles`。`--@style` 行在歌词文件缺少该样式时补上，已有同名样式时保留歌词文件里的版本。

## 各示例的输入要求

**ice_melt**：歌词行带逐音节 `\k`，日文样式 JP、中文样式 CN。模板用了 `all`，会作用到同一文件里所有 Effect 为空的可见行，文件里有别的对白时先把模板的 `all` 改成按样式匹配。尾句判定写在 `T.finale`（毫秒），换歌时要改。

**watercolor**：歌词行不需要 `\k`（整句效果）。`wc.scenes` 是按 ED 画面切换写死的颜色表（绝对时间），换歌时要重写。配置在“配置”那一行 code once 里。

**strawberry_jam**：歌词行改成样式 `12IN日v2` / `12IN中v2`，每句开头只放一个 `{\k1}`；最后加一行样式 `12IN罐v2`、Effect 为 karaoke 的“罐子行”（文字任意）。模板依赖的字体缺字补形存在 code once 里，只对原字体有效。

**live_chorus**：歌词行的 `\3c` 标记演唱者（阿尔玛 `&HC0A000&`、玛琪娜 `&H7A45E9&`、妮恩 `&H007FFF&`），说话人填“合唱”的行做渐变；日文行要排在对应中文行之前。曲目信息卡需要一条样式为“E10插入曲 - 标题”的 karaoke 行。原项目用 fontTools 测宽生成，用 GDI 重新套用时位置最多差 2 px。
